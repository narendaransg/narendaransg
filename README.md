### 💡 Featured ASIC & VLSI Projects

1. **8-Bit Asynchronous FIFO Physical Design & Routing Optimization (Synopsys ICC2)**
   - End-to-end individual layout across a $2,065.43\ \mu\text{m}^2$ core area ($68.41\%$ utilization) with dual-domain asynchronous clock trees (`wclk` & `rclk` at $1.50\text{ ns}$ period, $0\text{ ns}$ global skew, 0 DRC, $+0.16\text{ ns}$ Setup WNS).
2. **GPRS Core Block Physical Implementation (`gprs_top`) (Synopsys ICC2)**
   - 10-metal-layer macro-heavy physical design (33,286 final cells, 16 hard SRAM macros, $391,605.41\ \mu\text{m}^2$ core area) featuring data-flow flylines, M8/M7/M2 power mesh, and clean signoff via `route_eco`.
3. **Verilog Multi-Master Bus Arbiter (ChipThink VLSI Hackathon Finalist)**
   - Designed completely offline (zero internet/phone access) during the Maven Silicon & IEEE Hackathon; implements priority-based CPU arbitration with an 8-clock-cycle starvation prevention counter.
4. **Multi-Abstraction Verilog Half Adder & Switch-Level CMOS Verification (Synopsys VCS)**
   - Contrasted Dataflow (`assign`), Behavioral (`always @(*)`), Gate-Level, and Switch-Level CMOS (`pmos`/`nmos` networks wired to `supply1 VDD`/`supply0 VSS`) verified via SystemVerilog testbench (`tb_top`).
